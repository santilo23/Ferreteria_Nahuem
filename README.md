# Ferretería Nahuem - Sistema de Stock y Facturación

Sistema de escritorio local para control de stock, gestión de proveedores y emisión de comprobantes de pago no fiscales.

## Stack Tecnológico
- **Desktop:** Tauri v2
- **Frontend:** React 19 + TypeScript + Vite
- **Estilos & UI:** Tailwind CSS + shadcn/ui
- **Base de Datos & ORM:** SQLite + Prisma ORM
- **Testing:** Vitest + React Testing Library (TDD Red-Green-Refactor)
- **Arquitectura:** Clean Architecture (`/src/core`, `/src/infrastructure`, `/src/presentation`)
